# Lecciones de EmuRV — aprendé RISC-V desde cero

Currículo progresivo de 10 lecciones. Cada `leccion.s` es un programa
comentado que se abre en EmuRV (botón **«Abrir»**) y se recorre con
**«Paso»**, leyendo los comentarios: el texto de la lección es tu docente.

> Índice completo, mapa de aprendizaje y prerrequisitos por lección: se
> completa en la fase 3 de RP-9 (lecciones 1-3 disponibles).
